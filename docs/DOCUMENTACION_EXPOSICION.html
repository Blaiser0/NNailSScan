entrenar_modelo.py Entrenamiento IA

modelo nuevo/entrenar_modelo.py

Script de Python que entrena el modelo de IA con fotos de uñas y lo exporta como .tflite para que la app Android lo use sin internet.

  • EfficientNetB1 — red preentrenada en ImageNet, adaptada a enfermedades de uñas.
  • 240×240 px — tamaño de entrada del modelo (coincide con NailClassifier).
  • 3 fases — primero entrena la cabeza, luego ajusta capas del modelo base.
  • Salida — genera nail_model_nuevo.tflite y lo copia a app/src/main/assets/.

NailClassifier.kt IA en el celular

app/src/main/java/com/example/nnailscan/NailClassifier.kt

Clase Kotlin que ejecuta el modelo .tflite en el dispositivo. Recibe la foto del usuario y devuelve la enfermedad detectada con su porcentaje de confianza.

  • On-device — no necesita internet para analizar.
  • TensorFlow Lite — motor que corre el modelo en Android.
  • Entrada — foto redimensionada a 240×240 y convertida a números RGB.
  • Salida — nombre de la clase + confianza (ej. "onicomicosis", 87.3f).
⭐ Código más importante para la diapositiva — función classifyImage()
fun classifyImage(bitmap: Bitmap): Pair<String, Float> {
    // 1. Redimensionar la foto al tamaño que espera el modelo
        val resized = Bitmap.createScaledBitmap(bitmap, inputWidth, inputHeight, true)
        val inputBuffer = bitmapToByteBuffer(resized)
        val output = Array(1) { FloatArray(numClasses) }

    // 2. Ejecutar la predicción con TensorFlow Lite
        interpreter.run(inputBuffer, output)

    // 3. Elegir la clase con mayor probabilidad
        val probabilities = output[0]
        var bestIndex = 0
        var bestProbability = probabilities[0]
        for (i in 1 until numClasses) {
            if (probabilities[i] > bestProbability) {
                bestProbability = probabilities[i]
                bestIndex = i
            }
        }

    // 4. Devolver etiqueta legible + confianza en %
        return labels[bestIndex] to (bestProbability * 100f)
}

AuthRepository.kt Autenticación Firebase

app/src/main/java/com/example/nnailscan/firebase/AuthRepository.kt

Capa que conecta la app con Firebase Authentication. Gestiona login, registro y la sesión activa del usuario.

  • currentUser — indica quién está logueado en este momento.
  • signIn() — valida correo y contraseña contra Firebase.
  • signUp() — crea la cuenta y guarda el perfil en Firestore.
  • Protege el escaneo — sin sesión activa no se puede guardar el historial.
⭐ Código más importante para la diapositiva — sesión + registro con perfil
// Usuario activo — lo consulta ScanScreen antes de analizar
val currentUser: FirebaseUser?
    get() = auth.currentUser

// Iniciar sesión
suspend fun signIn(email: String, password: String): Result<Unit> =
    auth.signInWithEmailAndPassword(email.trim(), password).await()

// Crear cuenta + guardar perfil en Firestore
suspend fun signUp(email: String, password: String, fullName: String): Result<Unit> {
    val result = auth.createUserWithEmailAndPassword(trimmedEmail, password).await()
    val user = result.user ?: error("No se pudo crear la cuenta.")

    user.updateProfile(
        UserProfileChangeRequest.Builder().setDisplayName(trimmedName).build()
    ).await()

    firestoreRepository.saveUserProfile(
        UserProfile(uid = user.uid, fullName = trimmedName,
                  email = trimmedEmail, role = UserRole.USER)
        ).getOrThrow()
}
Qué decir en la exposición:
“Este repositorio es el portero de la app: verifica quién entra y mantiene la sesión. Al registrarse, no solo crea la cuenta en Firebase Auth sino que también guarda el perfil en Firestore. Cada escaneo queda vinculado al uid del usuario logueado.”
