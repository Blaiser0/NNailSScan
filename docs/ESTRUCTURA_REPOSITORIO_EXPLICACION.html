Explicación de la estructura

NNailScan — qué hace cada carpeta y archivo

El proyecto se divide en tres grandes bloques: la app Android (lo que usa el usuario), el entrenamiento de IA (Python) y los datos + Firebase (persistencia y seguridad).

📱 App Android — carpeta app/

Raíz

app/

Contiene toda la aplicación móvil. Está escrita en Kotlin con Jetpack Compose para las interfaces.

Configuración

build.gradle.kts

Archivo de configuración del módulo Android. Declara la versión de la app, el SDK mínimo y las librerías: Compose, Navigation, TensorFlow Lite, Firebase Auth, Firestore y Storage.

Incluye la regla noCompress "tflite" para que el modelo de IA no se dañe al compilar el APK.

IA embebida

src/main/assets/

Archivos que viajan dentro del APK y la app lee en tiempo de ejecución.

  • nail_model_nuevo.tflite — modelo entrenado listo para inferencia en el celular.
  • labels.txt — lista de enfermedades que el modelo puede detectar.
Entrada

MainActivity.kt

Punto de arranque de la app. Al abrirla, carga el grafo de navegación (NailScanNavGraph) y decide qué pantalla mostrar primero.

Inteligencia artificial

NailClassifier.kt

Ejecuta el modelo .tflite directamente en el dispositivo. Recibe una foto, la analiza y devuelve la enfermedad detectada con su porcentaje de confianza — sin necesidad de internet.

Datos

data/model/

Define la forma de los datos que maneja la app.

  • ScanRecord — registro de cada escaneo (resultado, confianza, foto, fecha).
  • UserProfile — perfil del usuario (nombre, correo, rol).
Backend / servicios

firebase/

Capa que comunica la app con Firebase.

  • AuthRepository — login, registro y sesión.
  • FirestoreRepository — guardar y leer escaneos e historial.
  • StorageRepository — subir fotos de escaneos y perfil.
  • ScanRepository — une IA + Storage + Firestore en un solo flujo.
Navegación

navigation/

Define las rutas de la app y el flujo entre pantallas. Por ejemplo: Inicio → Escanear → Resultado. También decide si el usuario ve login o la pantalla principal según tenga sesión activa.

Interfaz

ui/

  • screens/ — pantallas completas (Login, Home, Scan, Historial…).
  • components/ — piezas reutilizables (botones, headers, tarjetas).
  • viewmodel/ — lógica de cada pantalla (estado, llamadas a repositorios).
  • theme/ — colores y tipografía de NailScan.
Utilidades

util/

Funciones auxiliares: formatear etiquetas del modelo, comprimir imágenes, validar contraseñas, formatear fechas, etc.

Recursos

res/

Recursos estáticos de Android: textos en español (strings.xml), iconos, imágenes del launcher y temas visuales.

🧠 Entrenamiento IA — carpeta modelo nuevo/

Python

entrenar_modelo.py

Script que entrena el modelo con las imágenes del Dataset/ usando EfficientNetB1 (transfer learning). Al terminar exporta nail_model_nuevo.tflite y lo copia a app/src/main/assets/ para que la app lo use.

📂 Datos — carpeta Dataset/

Imágenes

Dataset/

Conjunto de fotos de uñas organizadas por carpetas; cada carpeta es una clase (enfermedad).

  • entrenamiento/ — imágenes con las que el modelo aprende.
  • validacion/ — imágenes para medir qué tan bien aprendió, sin usarlas en el entrenamiento.

Ejemplos de clases: onicomicosis/, dedo_azul/, unas_sanas/.

☁️ Firebase — raíz del proyecto

Seguridad

firestore.rules

Reglas de acceso a la base de datos. Definen quién puede leer o escribir escaneos, perfiles y datos de administrador. Por ejemplo: un usuario solo ve sus propios escaneos.

Base de datos

firestore.indexes.json

Índices de Firestore para consultas rápidas, como listar el historial de escaneos de un usuario ordenado por fecha.

En resumen: Dataset + entrenar_modelo.py crean el cerebro · assets + NailClassifier lo ejecutan en el celular · firebase/ guarda usuarios e historial · ui/ + navigation/ es lo que ve el usuario
