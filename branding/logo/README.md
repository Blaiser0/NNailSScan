# Logo NailScan

- `logo.png` — icono circular oficial (uña lineal sobre círculo gris).

## Logo con nombre (lockup)

El lockup **NailScan + eslogan** no es un PNG fijo: se renderiza en la app con el componente Compose `NailScanBrandHeader`, igual que en las guías de diseño.

Para marketing/exportación, captura pantalla desde:
- Pantalla de inicio (Welcome)
- Pantalla de login (versión compacta sin eslogan)

## Copiar a Android

```powershell
Copy-Item logo.png ..\app\src\main\res\drawable\nailscan_logo.png
```
